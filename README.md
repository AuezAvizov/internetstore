Базовое Single Page Application (SPA) для электронной коммерции, разработанное на **React**. 

Проект был создан в рамках экзаменационной работы по курсу веб-разработки для демонстрации уверенного владения фундаментальными концепциями React: компонентным подходом, управлением состоянием (State Management) и клиентским роутингом.

---

## ✨ Реализованный функционал

* 🔐 **Пользовательский доступ:** Базовая система авторизации для управления личным профилем.
* 📦 **Каталог и Корзина:** Просмотр ассортимента товаров и оформление заказов.
* 🧾 **История покупок:** Доступ к детализированной информации о прошлых заказах в личном кабинете.
* ❤️ **Избранное (Wishlist):** Возможность откладывать понравившиеся товары для будущих покупок.

---

## 🛠 Технологический стек

* **Библиотека:** React.js
* **Язык программирования:** JavaScript (ES6+)
* **Стилизация:** SCSS / CSS
* **Пакетный менеджер:** npm
